# US Accidents Severity Prediction

## Project Description
This project uses machine learning to predict the **severity (1-4)** of a traffic accident from temporal, weather, and road-feature information. It uses the US Accidents dataset (2022-2023 subset), compares two tree-based models, and evaluates them with metrics suited to a heavily imbalanced target (about 92% of accidents are Severity 2).

## Dataset
Dataset source: [US Accidents (2016 - 2023) on Kaggle](https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents)

The dataset is **not included** in this repository (multi-GB file). Download it from the link above, or in Colab use:

```python
import kagglehub
path = kagglehub.dataset_download("sobhanmoosavi/us-accidents")
```

**Subset used in this project**
- Accidents with `Start_Time` in 2022-2023 (about 2.0M rows), then a stratified random sample of 300,000 rows (stratified on `Severity`, `random_state=42`)
- After dropping rows with missing values and implausible durations (over 24 hours): **277,506 rows**
- 40 input features + the `Severity` target

## Preprocessing
- Dropped high-missingness columns (`End_Lat`, `End_Lng`) and high-cardinality identifiers (`Street`, `Zipcode`, `Airport_Code`, `County`)
- Removed rows with remaining missing values and rows with duration above 1,440 minutes
- Engineered temporal features: `Year`, `Month`, `Hour`, `DayOfWeek`, `Is_Weekend`, `Season`, `Is_Rush_Hour`, `Duration_Minutes`
- Label-encoded categorical columns, converted boolean road-feature flags to 0/1, standardized numeric columns
- 80/20 train/test split, stratified on `Severity` (`random_state=42`)

## Algorithms
- Random Forest (`n_estimators=100`)
- XGBoost (`n_estimators=100`, `max_depth=6`, `learning_rate=0.1`)

Both were also tested with class balancing (`class_weight='balanced'` for Random Forest, balanced sample weights for XGBoost).

Model selection was informed by Tang et al. (2025), who evaluated Decision Tree, XGBoost, and Random Forest on the same dataset:
Tang, J., Huang, Y., Liu, D., Xiong, L., & Bu, R. (2025). Research on Traffic Accident Severity Level Prediction Model Based on Improved Machine Learning. *Systems*, 13(1), 31. https://doi.org/10.3390/systems13010031

## Evaluation Metrics
- Accuracy
- Precision (macro and weighted)
- Recall (macro and weighted)
- F1-score (macro and weighted)
- AUC-ROC (macro, one-vs-rest)
- Confusion matrix

Macro averages treat all four severity classes equally, so they are the most informative given the class imbalance.

## Results
Test set: 55,502 rows. All values are from the actual runs in this project.

| Model | Accuracy | Macro Precision | Macro Recall | Macro F1 | Weighted F1 | AUC-ROC (macro) |
|---|---|---|---|---|---|---|
| Random Forest | 0.939 | 0.667 | 0.564 | **0.588** | 0.929 | 0.938 |
| XGBoost | 0.940 | 0.708 | 0.576 | 0.576 | 0.929 | 0.950 |
| Random Forest (balanced) | 0.936 | 0.656 | 0.536 | 0.566 | 0.925 | 0.936 |
| XGBoost (balanced) | 0.742 | 0.485 | 0.819 | 0.539 | 0.811 | 0.946 |

**Findings**
- The plain Random Forest had the best macro F1 (0.588) and was selected as the final model.
- Balanced sample weights raised XGBoost's macro recall (0.576 to 0.819) but caused a large precision drop and reduced accuracy to 74%.
- Both models detect Severity 4 (the rarest class) poorly, with recall of 0.06 (Random Forest) and 0.02 (XGBoost).
